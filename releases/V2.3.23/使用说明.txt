AD-批量打印 V2.3.23  全版本发布包
发布日期：2026-10-26
========================================

【本次更新要点】
· 新增「图块直接取最大包围盒」开关（打印预设 → 矩形框识别）：
   图框本身是一个图块（里面还有图签表格、明细表）时，勾上后顶层块按整体外包盒当图框，
   不再进块内部找矩形线（否则只认到"半张图"或表格框）。修剪块（XCLIP）不参与。默认关闭。
· 「四边留白」终于接通了：
   - 独立生效：填了四边数值就进留白模式，不再依赖上面的「留白」勾选框；
   - 可与统一留白叠加（四边 = 统一留白 + 各边偏移）；
   - 正数 = 扩大纸张并保持原比例（装订边可单独加大），负数 = 保持原纸、内容居中缩小；
   - 中望 / 浩辰 以前没有实现不等边定位（只有 AutoCAD 有），现在三平台一致。
· 安装器修复：
   - 同时读取 64 位与 32 位注册表视图 —— AutoCAD 2007/2008 这类 32 位 CAD 之前认不出来；
   - 自动加载注册表按 CAD 位宽写（32 位 CAD 写到 WOW6432Node），避免"装了但不自动加载"。
· 其余同 V2.3.22：图面只显示打印序号、点行不再整图 Regen、均衡档 A3 可识别。

【已知限制】中望 ZWCAD 2026 仍为"尽力兼容"（按 2025 API 编译），若 NETLOAD 报程序集版本错误，
请把 ZWCAD 2026 目录下的 ZwManaged.dll / ZwDatabaseMgd.dll 提供给我们按 26 版 API 重编。

【安装】用安装器勾选已装的 CAD 直接装；或按版本目录覆盖到插件目录（Plotters 一起覆盖），重启 CAD。
