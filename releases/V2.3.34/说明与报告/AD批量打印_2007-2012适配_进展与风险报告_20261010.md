## 三、net35 BCL 缺口（全部已修复，共约 1,100 处）

老 CAD 宿主运行在 CLR 2.0，BCL 缺一批现代类型。为避免在上百个文件里散布 `#if`，统一采用「**兼容垫片 + 源码替换**」：新文件 `src\Common\Compatibility\Net35Compat.cs`（所有目标共用；net48/net8 直接转发 BCL 真身，net35 走等价实现）。

| 缺失成员（.NET 版本） | 出现次数 | 处理方式 |
|---|---|---|
| `string.IsNullOrWhiteSpace`（4.0） | 384 | `Net35Compat.IsNullOrWhiteSpace` |
| `Path.Combine` 3/4 参重载（4.0） | 120 | `Net35Compat.Combine(params string[])` |
| `string.Join(string, IEnumerable/params)`（4.0） | 45 | `Net35Compat.Join`（4 个重载） |
| `Array.Empty<T>()`（4.6） | 20 | `Net35Compat.Empty<T>` |
| `Directory.EnumerateFiles`（4.0） | 5 | → `Directory.GetFiles`（签名一致） |
| `File.WriteAllLines(string, IEnumerable[,Encoding])`（4.0） | 2 | `Net35Compat.WriteAllLines` |
| `File.AppendAllLines`（4.0） | 2 | `Net35Compat.AppendAllLines` |
| `Stream.CopyTo`（4.0） | 1 | `Net35Compat.CopyTo` |
| `System.Threading.Volatile.Read`（4.5） | 1 | `Net35Compat.VolatileRead` |
| `IReadOnlyList/Collection/Dictionary`、`ISet<T>`（4.0/4.5） | 216 | 源码内改为 `IList/ICollection/IDictionary/HashSet`（net35~net8 全有且被 List/Dictionary/HashSet 实现，语义等价） |
| `IProgress<T>`、`CancellationToken(Source)`（4.0/4.5） | 48 | `Net35Polyfill.cs` 最小实现 |
| `ValueTuple<T1..T5>`、`TupleElementNamesAttribute`（4.7） | 128 | `Net35Polyfill.cs` 手写结构体（NuGet 的 System.ValueTuple 不支持 net35） |
| `PropertyInfo.GetValue(obj)`（4.5） | 1 | → `GetValue(obj, null)` |
| `RegistryKey.DeleteSubKeyTree(name, bool)`（4.0） | 1 | net35 退回单参 + try/catch |
| `Marshal.GetDelegateForFunctionPointer<T>`（4.5） | 1 | net35 用非泛型重载 + 强转 |

> 说明：`global using` 语法**不支持泛型别名**（无 type_parameter_list），故只读集合接口只能在源码层替换为等价基接口，未采用别名方案。

## 四、R17（AutoCAD 2007）托管 API 与新版差异（已逐处兜底）

这些是**真正的版本差异**，全部用 `#if NET35` 处理，并保留 2013+ 原逻辑：

| 新版 API（2013+） | R17 情况 | net35 处理 | 影响面 |
|---|---|---|---|
| `Database.ReadDwgFile(…, FileOpenMode, …)` | **第二参是 `System.IO.FileShare`** | net35 传 `FileShare.ReadWrite` / `FileShare.None` | 5 处 |
| `Curve.IntersectWith(…, IntPtr.Zero, IntPtr.Zero)` | 两参是 `int` | net35 传 `0, 0` | 3 处 |
| `Entity.Bounds` | 无 | net35 退回 `GeometricExtents` | 3 处（6 错） |
| `SpatialFilter.ClipSpaceToWorldCoordinateSystemTransform` / `OriginalInverseBlockTransform` | 无 | net35 跳过该候选，仅用块变换 | 3 处（6 错） |
| `ObjectId.ObjectClass` | 无 | net35 返回 `null`（按"拿不到类名即放行"约定） | 1 处 |
| `DBText.TextStyleId` | 无 | net35 跳过（用默认文字样式） | 2 处 |
| `MText.Text` | 无 | net35 改用 `Contents` | 1 处 |
| `Database.MLeaderStyleDictionaryId` | 无 | net35 跳过 MLeader 样式字典清理 | 1 处 |
| `HostApplicationServices.UserRegistryProductRootKey` | 无 | net35 不自动注册（返回 null 由调用方处理） | 1 处 |
| `PlotSettings.PlotTransparency` | 无 | net35 不设（由 `PLOTTRANSPARENCYOVERRIDE` 系统变量控制） | 1 处 |
| `TransientManager` / `TransientDrawingMode` | 无 | net35 整文件排除（临时标识功能不可用） | 1 文件 |
| `BlockTable.Count` | 无 | 探针改用 `Has("Model_Space")` | 1 处 |

> `FileOpenMode` → `FileShare` 这一条，已用「编译探针」实测确认（`db.ReadDwgFile(path, FileShare.ReadWrite, true, "")` 在 R17 下可编过），是确定性结论。

## 五、WPF 与 UI：旧版必须改 WinForms

net35 下 `UseWpf=false`（现代 SDK 的 WPF 仅支持 net472+/net core3.0+）。因此：

- **未编入 legacy 的 WPF 部分**：`Common\Views`（24 个 WPF 窗体）+ `Common\Commands`（UI 重）+ 4 个 Docnet PDF 后处理服务。
- **引擎邻接但含 WPF、已整文件排除**：`ThemeManager`、`CadDialog`、`CadWindowFocus`、`BatchPrintProgressSession`、`RectangleScanProgressSession`、`ScaleSettingsPicker`、`ArbitraryPaperPicker`（依赖 WinForms 版 `CustomScaleForm`）。
- **不能整文件排除**：`PlotStyleManager` 被出图引擎依赖（`ResolveJobStyle`/`NormalizeStyleName`/`ResolveStylePath`），已仅对其 3 个 UI 方法（`RestoreSavedStyle`/`TrySelectStyle`/`EditSelectedStyle`）加 `#if !NET35` 守卫。

**结论**：legacy 包目前是「引擎 + 无 UI 命令」骨架，命令 `ad-dy` 只做 R17 API 探针。旧版要能用，需按 WinForms 重写设置窗、图框清单窗、进度窗、关于页等——这是后续主线工作量。

## 六、风险与待办（按优先级）

1. **⚠️ 库来源存疑（最重要）**：你给的 `AutoCAD_2007_Lite_Library` 是免安装精简库。实测它连 `FileOpenMode`（2004 年起就存在）都缺失——虽然已查证 R17 的 `ReadDwgFile` 确实用 `FileShare`（真差异），但 `TextStyleId`、`ObjectClass`、`TransientManager` 等"本应存在"的缺失，提示该 `acdbmgd.dll`（2.9 MB）**可能被裁剪过**。
   → **建议**：用正版 AutoCAD 2007/2008 安装目录里的 `acmgd.dll`/`acdbmgd.dll` 复核一遍，避免把"精简库缺失"误判成"R17 差异"。
2. **2009–2012 未验证**：需 R18 的 `acdbmgd/acmgd 18.0.x`（2009/2010/2011/2012 各自的版本号）。本机仅装 2020/2026，无法取。拿到后只需照抄 legacy 工程换引用即可。
3. **位宽**：2007/2008 是纯 32 位 → 已 x86。**2009–2012 有 x64**，若用户用 64 位 2009–2012，需再加一条 `net35 + x64` 构建。
4. **功能降级**（net35 版）：临时标识、部分拆图空间过滤器精度、MLeader 清理、自动加载注册、透明打印强制。若这些对旧版重要，需另找 R17 等价实现。
5. **⚠️ 主线 DLL 已变化**：为共用源码，2013–2027 的 net48/net8 也一并重构（`IReadOnlyList`→`IList` 等）。编译与行为等价，但 md5 已变：net48 `c95702ec9b931849e810c262055e6f73`、net8 `3f89b1bdc7c8a59663407e87c723225d`。**建议对 2013–2027 做一次回归测试**；如需保持主线原样，可改用「构建期生成 legacy 专用源码副本」的方式（代价是构建变复杂）。重构前源码已备份：`D:\批量打印\_backup_src_before_net35_20261010.zip`。
6. **SharpZipLib 0.86.0**：net35 必须用它（1.x 无 net35 子集），但带 NU1902/NU1903 安全告警（仅警告，非错误）。
